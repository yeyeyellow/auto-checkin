# 2048 人人为我论坛自动签到

项目目录：`C:\Users\huangyaoyao\auto_checkin\hjd2048-checkin`。登录状态、依赖、脚本和日志均独立保存在此目录。

恢复运行器位于相邻 `../shared`；最新补试、互斥、记录保护与故障演练见 [恢复说明](../shared/README.md)，请保留整个 `auto_checkin` 目录结构。

## 运行

```powershell
cd C:\Users\huangyaoyao\auto_checkin\hjd2048-checkin
npm run checkin
```

脚本通过本机 Chrome 无头运行，不显示浏览器窗口。先从服务器两次确认本人今日签到状态；已签到跳过回复与验证码。

未签到时按用户授权自动完成：

1. 进入聚友客栈（板块 57），用论坛排序功能按发表时间排列，排除置顶主题，选择最新普通主题。
2. 不限制帖子发布日期；确认回复表单的板块、帖子编号及操作均正确，填写固定正文“感谢分享楼主好人”。
3. 提交后在帖子倒序页核实作者 UID、发表日期和正文。每天最多一次自动回复。
4. 签到心情默认选择“开心”，打开腾讯滑块，识别拼图的白色轮廓，并在背景相同高度匹配缺口。
5. 在原图分辨率下匹配，再换算弹层显示尺寸，使用浏览器鼠标事件拖动和校正位置。腾讯验证通过后，网站自己的回调提交签到表单。
6. 两次重新读取本人“签到服务台”，均显示今天已签到才报告成功。排行榜中的其他账号状态不作为判断依据。

定位置信度不足或验证被拒绝结束当前轮次；当天先快速尝试最多十轮，失败后间隔 20 秒，每轮重新核实签到状态并获取新验证码，最多提交一次验证码。成功立即停止；十轮失败后转入分钟级补试。已确认回复直接复用，回复待查证、签到结果不明或明确限流不进入快速重试。

## 首次登录与会话更新

```powershell
npm run login
```

这个命令显示独立 Chrome 窗口，自动关闭网站公告。用户手动登录后检测账号与退出入口，保存会话并关闭窗口。会话复用时保持首次登录的 User-Agent；本论坛实测默认无头浏览器标识会导致会话不被接受。

`session/state.json` 包含登录凭证，不要分享。Chrome 更新后仍使用保存的登录浏览器标识；重新手动登录会更新它。

## 防止重复回复

每个账号、每个香港日期生成独立记录：`session/reply-账号ID-日期.json`。点击提交之前记录 `PENDING`，在服务器上找到本人当天对应正文后记录 `CONFIRMED`。已确认的当天回复直接跳过；未确认的记录只复查，不再次发布。即使网络断开、脚本异常结束，也不会自动重复发帖。

若未找到对应回复，本次报告“回复失败”，后续每 30 分钟只查证原帖；确认后继续签到，不再次发布，不删除记录重试。记录损坏或字段不匹配仍需要处理。此记录针对本脚本发出的回复；不主动判断用户当天在其他帖子中手动回复过的内容。

## 自动启动

用户选择登录 Windows 后 3 分钟自动执行。安装入口为当前用户启动文件夹中的 `Hjd2048Checkin.vbs`，与老王论坛的启动项分别运行。PowerShell 隐藏，Chrome 无头，不依赖 Codex 打开。

Windows 可能延迟启动项处理，180 秒从入口执行时开始计时；恢复任务每 5 分钟检查当天登录周期的到期补试，不跨日启动新签到。请保留本项目与相邻 `shared` 目录。

```powershell
# 安装或重新安装
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-startup.ps1
# 关闭此网站的自动启动，保留项目与会话
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\remove-startup.ps1
```

## 日志和结果

后台日志：`artifacts/startup.log`，自动追加，不自动打开。最近结果：`artifacts/last-result.json`。

- `SUCCESS`：签到成功，退出码 0。
- `ALREADY_SIGNED`：今日已签到，退出码 0。
- `LOGIN_EXPIRED`：登录过期，退出码 2；手动执行登录命令更新。
- `VERIFICATION_FAILED`：验证码、签到提交或最终状态未确认，退出码 3。
- `REPLY_FAILED`：回复前置条件、提交或结果无法确认，退出码 6。
- `ERROR`：网络或页面访问异常，退出码 4。
- `BUSY`：有其他签到实例运行，退出码 5。

Windows 系统互斥在进程退出或重启后自动释放；旧 `run.lock` 不再参与判断。后台签到有 11 分钟看门狗，接近期限时剩余轮次由恢复任务继续。暂时错误先快速尝试十轮、失败间隔 20 秒，再持续慢速补试；限流和回复不确定延后 30 分钟。登录过期、无法确认表单或记录损坏需要处理。程序失败不自动弹窗。
